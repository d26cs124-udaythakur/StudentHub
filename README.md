# StudentHub Portal

## Project Description

StudentHub is a web-based student portal designed to provide students with a centralized platform to access academic information, notices, events, resources, assignments, and other student-related services.

The project is being developed as a semester-long project with a structured and maintainable folder organization.

## Objectives

* Provide a centralized student portal.
* Make student information easily accessible.
* Provide simple and user-friendly navigation.
* Display notices, events, and academic resources.
* Provide student profile and dashboard functionality.
* Create a structured project that can be extended in future practicals.

## User Roles

### Student

* Register and log in.
* View the student dashboard.
* Manage profile information.
* View courses and academic resources.
* View notices and events.
* Check assignments.
* Submit feedback.

### Admin

* Access the admin panel.
* Manage student-related information.
* Manage notices and events.
* Manage portal content and resources.
